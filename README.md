# caerno.github.io

Personal site of Dmitry Kirsanov: one static landing in two languages, built from YAML content with a
single Node script and no framework. Live: https://caerno.github.io/ (English), https://caerno.github.io/ru/.

The hero is a character field drawn on a canvas: five work cases and the methods they share, laid out
from the case data itself. Everything visible on the page comes from `data/`; the markup, styles and
behaviour live in `build.mjs` and `src/`.

## Build

```bash
npm ci            # once: the only dependency is the YAML parser
npm run build     # data/ + src/ -> dist/ (publishable) and preview/ (every slot visible, for editing)
npm run serve     # build and serve dist/ on http://localhost:8138
npm test          # smoke test of dist/ in headless Chromium (Playwright for Python)
```

GitHub Pages deploys `dist/` from `main` through `.github/workflows/pages.yml`.

## Layout

| Path | What |
|---|---|
| `build.mjs` | the builder: reads `data/`, renders `dist/index.html` and `dist/ru/index.html`, inlines `src/` |
| `src/landing.css`, `src/landing.js` | page styles and behaviour (deck views, scroll nudges, case accordion); inlined, no separate requests |
| `src/field.js` | the canvas engine of the hero figure and of the occupation cloud |
| `src/brand/`, `tools/brand.py` | site mark (pixel star): favicons copied next to both pages, the mark in the menu, logo PNGs; regenerate with `python3 tools/brand.py`. Link preview images `og.png` / `og-ru.png` (1200×630, hero snapshot): `node build.mjs && python3 tools/og.py` |
| `data/landing.yaml` | page layout (`_layout`: blocks and cards in page order, `show`, view and position toggles) and every text slot with its `en` / `ru` variants and the picked one (`pick`, `-1` = removed) |
| `data/profile.yaml` | name, role line, status line, links |
| `data/cases/*.yaml` | one file per case: period, organisation, domain, tagline, methods, projects; the hero figure is built from `methods` |
| `data/artifacts.yaml` | public projects with their links (kinds: `wiki`, `github`, `dataset`, `notebook`, `live`) |
| `data/fits.yaml` | kinds of work, each pointing at the cases that prove it |
| `data/atoms/capabilities.yaml` | skills per case; the grey texts of the hero figure are drawn from here |
| `data/i18n/ru.yaml` | Russian overlay keyed like `case.<slug>.tagline`; English is the canon inside each entity |
| `data/derived/hero-points.json` | points of the occupation cloud, generated by `tools/hero-points.mjs` from O*NET interest data |
| `data/career/` | sources of the "Your Thing" interest test, see below |
| `tests/smoke.py` | Playwright smoke test |

Texts are edited in a local admin page (PAL, `/site`): it reads and writes the same YAML files and rebuilds
the page, nothing on the site is edited by hand in HTML.

## "Your Thing" (`/your-thing/`)

An adaptive interest test with 923 O*NET occupations in one space. Its sources live here
(`data/career/`, `src/career.*`, `tools/career-*`), the built page is published from the separate
repository `Caerno/your-thing`:

```bash
node tools/build-career.mjs /path/to/your-thing --pretty
```

| Piece | Where |
|---|---|
| engine: joint Gaussian posterior over 11 scales, expectation propagation, next item by expected variance reduction | `src/career.js` |
| RIASEC bank (48 items, GRM parameters) | `data/career/items.json` ← `tools/career-calibrate.py` |
| joint RIASEC × Big Five prior, TIPI parameters | `data/career/model.json` ← `tools/career-joint.py` |
| TIPI (10 items), Klimov DDO (20 pairs), page texts, en / ru | `data/career/tipi.json`, `ddo.json`, `texts.json` |
| O*NET 30.0 occupations and the ESCO / Russian crosswalk | `data/career/occupations.json`, `xwalk.json` ← `tools/career-occupations.py`, `career-xwalk.py` |
| constraint questions (Russian page) and Russian titles | `data/career/constraints.json`, `ru-names.json` ← `tools/career-constraints.py` |
| README of the published repository | `data/career/readme.md` (copied by the builder) |
| where the raw data for `tools/*.py` lives | `tools/sources.json`, local and not in git; template `tools/sources.example.json` |
| engine check without a browser | `node tools/career-test.mjs [persons]`, `node tools/career-sim.mjs [persons] [questions]` |
| page check in a browser | `python3 tests/career.py` (part of `npm test`) |

Answers never leave the visitor's browser (`localStorage`). Occupation data: O*NET 30.0, CC BY 4.0.
